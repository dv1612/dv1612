## How I work

**Clean before you model.** Every pipeline logs what it removed and why. In the retail project that
meant folding four different SKU spellings onto one key before anything could be joined; in the RFM
project, 149,217 rows dropped for reasons that are each counted and printed.

**Measure against the right denominator.** The SaaS cohort model excludes cohorts too young to have
reached a given month — including them understated month-12 retention by roughly five times. That
kind of decision is documented in each case study, because it is the difference between a chart and
an analysis.

**Deliver where people already work.** The SQL produces views; the DAX is written out and commented;
the dashboards exist as PDFs so a stakeholder without Power BI can still read the finding.
